# 设备坞 4.0 使用文档

适用版本：**4.1.1**

更新日期：2026-11-19

设备坞是一款面向 Android 设备的桌面管理工具，基于 Electron、ADB 和 scrcpy。它把门店、机房和测试环境里常用的设备操作集中到一个窗口里：连接设备、看画面、传文件、装应用、查日志、跑终端、检测硬盘和 eMMC。

> 4.0 起设备坞独立演进，不再包含 APM 远程的账号登录、按 MAC 查设备和 frpc 穿透功能。连接方式只有 USB 和局域网 ADB。

## 1. 系统要求

### 电脑端

| 平台    | 支持情况                                |
| ------- | --------------------------------------- |
| macOS   | Apple Silicon（arm64），macOS 12 及以上 |
| Windows | Windows 10 / 11，x64                    |
| Linux   | 未提供正式安装包，可自行从源码构建      |

设备坞自带 ADB，不需要另外安装 Android SDK 或 Platform Tools。

### 设备端

- Android 设备已开启「开发者选项」和「USB 调试」
- 局域网连接需要设备与电脑在同一网段，且设备 ADB 端口可访问
- Android 11 及以上使用「无线调试」时，需要配对码
- 投屏依赖 scrcpy-server，Android 5.0 及以上设备通常可用；不同厂商 ROM 可能有差异

## 2. 安装与启动

### macOS

1. 打开 `设备坞-4.1.1-mac-arm64.dmg`
2. 将「设备坞」拖入「应用程序」
3. 首次打开如果被 Gatekeeper 拦截，右键应用图标选择「打开」，或在「系统设置 → 隐私与安全性」中允许

当前安装包未使用 Apple Developer ID 签名，首次启动出现安全提示属于正常现象。

### Windows

提供两种形式：

- `设备坞-4.1.1-win-x64.exe`：NSIS 安装版，支持选择安装目录、创建桌面和开始菜单快捷方式
- `设备坞-4.1.1-win-x64.zip`：免安装版，解压后直接运行

首次运行如果出现 SmartScreen 提示，选择「更多信息 → 仍要运行」。

安装包未做代码签名，这是预期行为。

### 首次启动

启动后进入「设备连接」页。左侧是功能导航，右侧是当前设备区域；没有连接设备时，大部分页面会提示「未连接设备」。

## 3. 连接设备

### 3.1 USB 连接

1. 用数据线连接 Android 设备和电脑
2. 在设备上确认「允许 USB 调试」授权弹窗
3. 设备坞会自动发现设备，并显示在「设备连接」列表中
4. 点击设备行即可切换为当前设备

如果设备显示「未授权」，请在设备上重新确认授权；仍未出现时，可在系统设置中撤销 USB 调试授权后重新插拔。

### 3.2 局域网 ADB

设备与电脑需要处于同一局域网。推荐先通过 USB 连接，再切换无线模式：

1. USB 连接设备
2. 在「设备连接」工具栏点「无线模式」
3. 设备坞会尝试将设备切换到 TCP/IP ADB，并显示设备 IP
4. 拔掉 USB 后，用 `IP:端口` 连接，默认端口通常是 `5555`

也可以直接在工具栏输入 `IP` 和端口，点「连接」。

> 网络设备不会自动执行 `adb root`，因为 adbd 重启会断开当前 TCP 连接，门店设备可能无法自动恢复。

### 3.3 Android 11 无线调试配对

Android 11 及以上支持「无线调试」配对：

1. 在设备上打开「开发者选项 → 无线调试」
2. 点「使用配对码配对设备」，记下配对码和配对端口
3. 在设备坞点「配对」，输入配对信息
4. 配对成功后，再用设备的无线调试 IP 和端口连接

### 3.4 扫描局域网

点「扫描局域网」后，设备坞会扫描当前网段并尝试连接发现的 ADB 设备：

- 扫描过程中按钮会显示进度，例如 `扫描 120/254`
- 发现设备后会显示设备数量和在线数量
- 扫描到的设备会加入列表，可直接点击切换

扫描不到设备时，优先检查：

- 电脑和设备是否在同一网段
- 路由器是否开启了 AP 隔离/客户端隔离
- 设备 ADB 端口是否开放
- 防火墙是否拦截了局域网访问

### 3.5 多设备

设备连接页支持多台设备同时在线。点击列表中不同设备行可切换当前设备；文件、应用、日志、终端等页面会随当前设备切换。

## 5. 功能页面

### 5.1 概览

显示当前设备的基础信息和运行状态：

- 设备名称、品牌、型号、序列号
- Android 版本、内核版本、处理器、CPU 核心数
- Root 状态
- 网络、IP、MAC
- 存储、内存、分辨率
- 字体缩放

工具栏还提供：

- **ADB CLI**：在电脑上执行 ADB 命令
- **重启 ADB Server**：ADB 无响应时使用
- **Root 模式**：尝试以 root 身份执行 ADB
- **端口映射**：把设备端口映射到电脑
- **远程控制器**：用电脑键盘/鼠标控制设备
- **刷新**：重新读取设备信息

> Root 操作会影响设备，门店设备请谨慎使用。

### 5.2 文件

文件页用于浏览和管理设备文件。

- 首次进入默认打开内部存储 `/sdcard/`
- 会记住每台设备上次浏览的目录
- 支持「根目录」「sdcard」「全盘」快速切换
- 支持新建文件夹、上传、下载、重命名、删除
- 支持当前目录搜索和全盘搜索
- 支持多选批量操作
- 底部/侧边会显示传输进度
- 图片、文本、音视频等文件支持预览；其他文件显示系统图标

如果目录为空或无法读取，通常是 Android 存储权限或设备未授权导致。

### 5.3 应用

应用页支持列表和图标两种视图。

- 查看系统应用/第三方应用
- 搜索应用
- 安装 APK：点「安装」选择文件，或直接把 APK 拖入窗口
- 导出 APK
- 启动、停止应用
- 卸载应用
- 清除应用数据
- 查看包名、版本、安装时间等信息

系统应用被停用可能影响设备功能，操作前请确认。

### 5.4 进程

显示设备当前进程和资源占用：

- 进程名、PID、CPU、CPU 时间、内存、用户
- 可切换「仅显示应用」，过滤系统进程
- 支持结束进程

结束系统关键进程可能导致设备重启或界面异常，请只操作确认过的应用进程。

### 5.5 性能

实时展示设备运行指标：

- CPU 使用率
- 内存占用
- FPS
- 电池/温度等设备支持的信息
- 历史曲线

用于判断设备卡顿、发热或异常占用，不替代专业性能分析工具。

### 5.6 硬盘检测

硬盘检测把两类存储放在同一张表里：

1. **外接 SATA/USB 硬盘**：通过 DiskToolkit 读取 SMART 信息
2. **内置 eMMC**：读取 JEDEC Ext CSD 健康字段

外接盘可查看：

- 型号、容量、温度
- 通电时长、通电次数
- SMART 总体状态
- 序列号

eMMC 可查看：

- 厂商、型号、容量、序列号、生产日期
- `pre_eol_info` 预留块状态
- `life_time_estimation A/B` 寿命估计
- 综合结论
- 数据来源（ioctl / debugfs 等）

eMMC 健康字段在部分设备/内核上需要 root；读不到健康字段时，仍会显示身份信息并把状态标为未知。选中任意一行可在下方查看详细报告。

> 硬盘检测依赖随包的 DiskToolkit 资源；如果你的构建没有包含厂商 CLI，需要将对应二进制放到 `resources/disktool/` 后再使用。

### 5.7 终端

终端页提供交互式 ADB Shell：

- 支持多个标签，每个标签是独立 shell 会话
- 可新建、切换、关闭标签
- 提供常用快捷命令
- 支持复制、粘贴和命令历史

终端命令直接作用于设备，执行 `rm`、`reboot`、`pm clear` 等命令前请确认目标设备。

### 5.8 截屏

截取设备当前屏幕：

- 点「重新截图」刷新
- 支持保存到电脑
- 设备离线或黑屏时可能截到空白图

### 5.9 日志

日志页实时接收设备 logcat：

- 标准视图/紧凑视图
- VERBOSE、DEBUG、INFO、WARNING、ERROR 级别过滤
- 按包名、Tag 过滤
- 暂停/继续
- 自动滚动到底部
- 软换行
- 保存日志到文本文件
- 清空日志
- 重启日志流

首次打开时页面会显示「正在连接日志流…」或「等待设备日志…」；暂停后会显示「日志已暂停」。如果一直没有日志，先确认设备在线，再点工具栏的重启按钮。

## 6. 投屏

在设备连接页或设备卡片上点「投屏」，会打开该设备的独立投屏窗口。

### 6.1 基本操作

- 鼠标点击 = 触摸
- 鼠标拖动 = 滑动
- 键盘输入 = 设备输入
- 支持全屏
- 支持开始/停止录制
- 支持同步设备剪贴板

### 6.2 信号源切换

投屏窗口顶部工具栏有一个**九宫格图标**，鼠标悬停显示「信号源」。点击后可选择：

- 主屏
- 副屏（设备支持多 display 时）
- 其他设备上报的显示源

选择后投屏会自动重连到对应信号源。

### 6.3 投屏设置

点投屏工具栏的设置按钮，可调整：

- **码率**：4–50 Mbps
- **最大尺寸**：720 / 1280 / 1920 / 原始分辨率
- **编码**：H.264 / H.265（设备不支持 HEVC 时自动回退 H.264）
- **帧率**：15 / 30 / 60 FPS
- **音频**：关闭 / 转发设备声音（实验）

音频使用 Opus 48kHz 独立通道，默认关闭；部分设备没有可用的音频输出，此时只保留画面。

### 6.4 投屏异常

- **一直黑屏**：切换信号源，或在设备上点亮屏幕
- **没有画面但状态是 live**：检查设备是否在息屏/副屏无输出
- **花屏/解码失败**：把编码切回 H.264，降低最大尺寸或码率
- **控制无效**：重新打开投屏窗口；网络设备掉线后需要重新连接 ADB
- **音频没有声音**：确认设置里音频已开启，并检查设备是否静音/没有音频输出

## 7. 设置

点主窗口的设置按钮打开设置弹窗。

### 外观

- **主题**：跟随系统 / 浅色 / 深色
- **语言**：跟随系统、中文、繁体中文、English、Français、Português、Español、Русский、Türkçe、العربية
- **原生标题栏**：使用系统标题栏代替自绘标题栏
- 修改语言和原生标题栏后需要重启应用生效

### ADB

- **ADB 路径**：指定自定义 adb 可执行文件；留空使用随包 ADB
- **退出时结束 adb**：关闭设备坞时是否停止 ADB Server
- **重启应用**：立即重启设备坞

> 如果自定义 ADB 路径无效，设备坞可能无法发现设备。改回默认值或重新选择正确的 adb。

## 8. 常见问题

### 设备显示「未授权」

在设备上打开开发者选项，撤销 USB 调试授权，然后重新插拔并确认授权弹窗。

### 设备显示「离线」

- 检查数据线/USB 口
- 网络设备检查 IP、端口和 Wi-Fi 是否变化
- 在概览页点「重启 ADB Server」
- 重新插拔或重新执行 `adb connect IP:端口`

### 局域网扫描不到设备

- 确认电脑和设备在同一网段
- 关闭路由器的 AP 隔离/客户端隔离
- 确认设备 ADB TCP 端口已开启
- 检查电脑防火墙
- 尝试直接输入 `IP:5555` 连接

### 文件页打不开目录

- 确认设备已授权
- Android 11+ 的某些目录受分区存储限制
- 尝试进入 `/sdcard/` 或使用全盘搜索
- 设备掉线后回到连接页重新连接

### 日志页空白

- 确认设备在线
- 点日志工具栏的「重启」按钮
- 切换级别到 VERBOSE
- 清空过滤器后重试

### eMMC 只显示型号，没有健康度

eMMC 健康字段需要内核/驱动暴露 Ext CSD，部分设备需要 root。可以尝试：

1. 在概览页开启 Root 模式
2. 重新扫描
3. 如果设备没有 `su`，只能显示身份信息和「未知」状态

### 投屏窗口没有「信号源」选项

只有设备上报多个 display 时才会出现多个信号源；单屏设备只显示主屏。检查设备是否支持副屏输出。

### macOS 提示应用已损坏/无法验证

这是未签名安装包的 Gatekeeper 提示。右键应用选择「打开」，或在系统设置中允许。不要从不明来源下载替换包。

### Windows SmartScreen 拦截

点「更多信息 → 仍要运行」。安装包未做代码签名，首次运行出现提示是正常的。

## 9. 安全与隐私

- ADB 具有很高的设备控制权限，请只在可信网络中使用
- 不要把 ADB 5555 端口暴露到公网
- 局域网扫描只扫描当前网段，不会上传设备信息
- 设备坞不包含 APM 账号、frpc 穿透或云端业务
- 投屏、剪贴板同步和文件传输都在本机与设备之间进行
- 使用 Root、清数据、卸载、结束进程、执行 shell 命令前，请确认目标设备和操作后果

## 10. 版本与反馈

当前文档对应设备坞 **4.1.1**。功能会随版本迭代，界面文案和按钮位置以实际安装版本为准。

### 导出诊断信息

1. 打开菜单「设备坞 → 关于设备坞」。
2. 点击「导出诊断信息」并选择保存位置。
3. 将生成的 `devicedock-diagnostics-*.json`、复现步骤和问题截图一起反馈。

诊断包包含应用/运行环境版本、ADB 状态、设备概览、应用列表探测、设备服务版本、最近日志和失败操作 ID。它不会采集剪贴板、屏幕内容或文件正文，并会自动移除访问令牌、密码类字段和本机用户目录。

- 项目主页：https://github.com/xiaoyangc-ch/device-dock
- 问题反馈：请在 GitHub Issues 中附上设备坞版本、操作系统、设备型号/Android 版本和复现步骤
- 开源许可：MIT；第三方组件声明见仓库 `NOTICE`
